# Colorado Travel Blog

Static travel-blog starter site based on a 7-day Colorado family road trip.

## Route
Denver → Colorado Springs → Royal Gorge → Twin Lakes → Independence Pass → Aspen / Maroon Bells → Glenwood Springs → Vail → Denver

## Files
- `index.html` — main site
- `styles.css` — responsive styling
- `script.js` — smooth scrolling
- `assets/` — place your photos here

## Run locally
Open `index.html` in a browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
